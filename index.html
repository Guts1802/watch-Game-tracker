Settings, import & backup

Free Gemini key: get one at aistudio.google.com. It is saved only on this device.

Sync between devices

Keeps your progress the same on every device using a private GitHub Gist. Only your tracker list is uploaded. Your Gemini key and GitHub token never leave the device. On each device, paste a GitHub token that has Gist permission and press Save & sync.

Import: paste a franchise block sent by Claude (or a backup) and press Import.
